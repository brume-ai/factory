# factory

Usine de developpement pilotee par les issues GitHub : une boucle ralph prend
les cartes une par une et mene chacune jusqu'a une pull request prete a relire,
avec un agent NEUF par carte.

Extrait de [Brume](https://github.com/Brume-ai) au SHA `12ac9e92`, ou cet
outillage est ne et a paye ses lecons (les commentaires dates des scripts sont
ces lecons ; ils voyagent avec le code). Generalise ici pour etre consomme par
n'importe quel depot via un submodule git.
